# integrator Plugin

Skills for building integrations, automations, and services with WSO2 Integrator. Installing
this plugin also installs the Ballerina plugin, which writes, builds, runs, and tests the code.

## Skills

| Skill | Triggers |
|-------|----------|
| **integrator** | Any request that names WSO2 Integrator: add or change an integration, automation, service, or library integration in a project |

Code work is handed to the **ballerina** skill from the Ballerina plugin.

## Getting Started

See the [installation instructions](../../README.md#installation) in the main README. Then try:

```
> Add a new integration to my WSO2 Integrator project that syncs Salesforce contacts to a database.
```
```
> Create a WSO2 Integrator automation that posts new GitHub issues to Slack.
```
```
> Add a library integration for shared date helpers to my WSO2 Integrator project.
```
